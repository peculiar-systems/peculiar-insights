# For agents

The repository ships a document written for an agent to integrate Insights into a product: what to ask the person for, the rules that cannot be bent, event design, per-platform steps that point at worked examples, verification through Grafana, and pitfalls.

Hand the agent this file:

[AGENT.md on GitHub](https://github.com/peculiar-systems/peculiar-insights/blob/main/AGENT.md)

It is complete on its own. The agent needs, from you, the server URL per environment, the ingest key per environment, the current privacy policy version string, and the package or module names the product owns.
